# Changelog

All notable changes to Executive PA, per development phase.

## [Phase 7] - Production Hardening, PWA Polish & Zero-Cost Deployment

### Added
- `/api/health` liveness endpoint (no sensitive data, no dependency checks).
- Reminder scheduler wired into server lifecycle: starts after listen (skipped in tests), stops on graceful shutdown. Previously the scheduler never started from `index.js`.
- PWA icons (192/512, maskable-safe) generated by `server/scripts/generate-icons.js` (pure Node, no image deps).
- Service worker update flow: versioned cache (`v2`), stale-while-revalidate for static assets, `SKIP_WAITING` message support, and an in-app "Update available → Refresh" banner via `useServiceWorkerUpdate`.
- Database operations: `npm run db:backup` / `npm run db:restore` (pg_dump/psql wrappers with production-name guard) — see `docs/BACKUP_RESTORE.md`.
- Server regression suite `server/tests/phase7.test.js` (11 tests, node --test) covering health/readiness, auth guard, single-user sessions, validation whitelisting and scheduler safety.
- Zero-cost deployment configs: `render.yaml` (API, `prisma migrate deploy` on start, `/api/ready` health check) and `netlify.toml` (SPA build, SW headers, SPA fallback).
- Documentation: `README.md`, `ARCHITECTURE.md`, `docs/DEPLOYMENT.md`, `docs/BACKUP_RESTORE.md`, `docs/TROUBLESHOOTING.md`.

### Changed
- `client/src/main.jsx`: service worker registration moved into `useServiceWorkerUpdate` (single registration point, update detection).
- `client/public/sw.js`: cache versioning + SWR strategy + message channel (network-only for `/api/*` unchanged).
- `server/package.json`: test script targets `tests/**/*.test.js` (Windows-safe glob).

### Security
- Verified existing posture: Helmet, CORS allowlist, rate limiting, Zod whitelists, safe error masking in production, secret-redacting logger, session JWT separate from Microsoft tokens.
